# 英语单词词根拆解

## 用法

- `/word-breakdown syllabus` — 拆解单词，默认使用实用记忆版
- `/word-breakdown syllabus 词源版` — 追溯历史词源
- `/word-breakdown syllabus 形态版` — 按前缀/词根/后缀拆解

## 执行规则

1. 分析单词的前缀、词根、后缀
2. 使用**实用记忆版**模板生成文档（除非用户指定其他版本）
3. 文档保存到 `~/Desktop/<单词>词根拆解.md`
4. 输出简洁确认信息

```markdown

\`\`\`

## 核心记忆句

> <用含义串联的记忆句> = **<单词>**（<中文释义>）
```
